# ティラノスクリプト向け 弓道（的当て）ミニゲーム制作仕様書

## 1. 概要・動作環境
- **概要**: 弓道をモチーフにした、照準と的のタイミングを合わせるミニゲーム。
- **プラットフォーム**: ティラノスクリプト（PC / スマホのタッチ操作両対応）
- **画面解像度**: 1280 × 720 px（基準解像度）
- **実装方式**: JavaScript（`[iscript]` / HTML5 Canvas）を用いて画面上に全画面オーバーレイ等で描画・動作させ、ミニゲーム終了時に結果を変数に格納して元のシナリオに戻る。

---

## 2. 定数・設定パラメータ（調整用オブジェクト）
コードの保守性・調整をしやすくするため、ゲームパラメータは冒頭で一元管理できるオブジェクト形式（`CONFIG`）で定義してください。

```javascript
const CONFIG = {
  // --- 的・判定のサイズ設定 ---
  targetScale: 0.6,         // 的の表示倍率（基準サイズからの変更用）
  hitBoxRadius: 100,        // 「中り」判定となる的中心からの半径（px）

  // --- ブレ（揺らぎ）設定 ---
  initialSwayRadius: 150,   // スタート時の初期ブレ半径（px）
  minSwayRadius: 20,        // 限界（ゲージMAX直前）まで長押しした時の最小ブレ半径（px）
  swayMoveDuration: 200,    // 次の目標点へ直線移動する時間（ミリ秒）

  // --- 制限時間・判定設定 ---
  maxHoldTime: 10.0,        // 暴発までの長押し時間（秒）
  totalShots: 4,            // 合計射数（4回固定）

  // --- ティラノスクリプト連携変数名 ---
  resultVariableName: 'f.kyudo_result' // 復帰時に代入するティラノ変数
};
```

## 3. 「照準のブレ（揺らぎ）」アルゴリズム仕様
的は画面中央に固定し、照準（クロスヘア）を移動させます。ランダムノイズ（微振動）ではなく、プレイヤーが**「狙いを定めている感覚」**を得られるよう、照準を目標点から次の目標点へ直線的に移動させてください。

### 【ブレ移動の計算ロジック】
1. **基準点**:
   - 固定された的の中心を原点 $(0, 0)$ とし、照準の位置を的中心からの相対座標で管理する。
2. **現在のブレ半径 $R$ の算出**:
   - 長押し時間 $t$（$0 \text{秒} \sim \text{CONFIG.maxHoldTime}$）の経過に応じて、ブレ半径 $R$ を `initialSwayRadius` から `minSwayRadius` へ小さくする（長押しするほど拡大＋ブレ幅縮小）。新しい目標点を決めるたびに、その時点の $R$ を使用する。
3. **初期設定（第1目標点）**:
   - クリック/タッチ開始時、照準は的の中心 $(0, 0)$ からスタートし、ランダムな角度 $\theta_0$ ($0^\circ \sim 360^\circ$) を決定。
   - 目標座標 $P_0 = (R \cdot \cos\theta_0, R \cdot \sin\theta_0)$ を設定し、照準をそこへ移動させる。的の位置は動かさない。
4. **継続的な軌道移動（対角線 $\pm 45^\circ$ の目標点決定）**:
   - 現在の目標位置の角度が $\theta_{\text{current}}$ である場合、次の目標角度 $\theta_{\text{next}}$ は**対角位置（$\theta_{\text{current}} + 180^\circ$）を中心とした $\pm 45^\circ$ の範囲**からランダムに選定する。
     $$\theta_{\text{next}} = \theta_{\text{current}} + 180^\circ + \text{random}(-45^\circ, +45^\circ)$$
   - 現在のブレ半径 $R$ を用いて、次の目標座標 $P_{\text{next}} = (R \cdot \cos\theta_{\text{next}}, R \cdot \sin\theta_{\text{next}})$ を算出する。長押し中は目標点を更新するたび、その時点の経過時間から $R$ を求める。
5. **補間（直線移動）**:
   - 前の座標 $P_{\text{start}}$ から新しい目標点 $P_{\text{next}}$ まで、線形補間で `swayMoveDuration`（ミリ秒）かけて直線移動させる。補間率を $u=\mathrm{clamp}((現在時刻-移動開始時刻)/swayMoveDuration, 0, 1)$ とし、座標は $P(u)=P_{\text{start}}+(P_{\text{next}}-P_{\text{start}})u$ とする。イージングは適用しない。
   - 到達したら手順4〜5を繰り返す。

## 4. ゲームの進行フロー・詳細ルール

1. **待機状態**:
   - 画面中央に固定された的が表示された状態でスタート。
   - 画面上部UI等に「現在の試行回数（例: 1/4 射目）」および「現在の的中数」を表示。
2. **長押し開始（エイム・溜め）**:
   - 画面中央の的に重ねて照準を表示する。
   - マウスダウン（またはタッチ開始）で時間経過ゲージ（0〜100%）が増加開始。
   - 時間経過に伴い的が連続して拡大（ズームイン）し、同時に**「3. 照準のブレ移動アルゴリズム」**に従って照準が直線移動する。的の中心は移動させない。
3. **暴発処理**:
   - ボタンを放さずにゲージが 100%（`CONFIG.maxHoldTime`）に達した場合、強制的に矢が放たれて画面枠外のあらぬ方向へ飛んで「ハズレ」確定となる。
4. **着弾判定（ボタン離し）**:
   - ゲージ100%未満でマウス（指）を離すと矢が放たれる。
   - 放たれた瞬間の照準位置と、固定された的の中心位置との距離を計算。
   - 距離が `CONFIG.hitBoxRadius` 以内であれば「中り」、それ以外は「ハズレ」と判定。
   - 着弾した位置に着弾点（黒い点）を描画する。過去の試行で残った着弾点も画面上に保持する。
5. **ループとシナリオ復帰**:
   - 1〜4を計4回繰り返し、終了後に的中数に応じてティラノ変数 `f.kyudo_result`（指定の変数名）に以下の文字列を格納してシナリオに戻る。
     - **4回的中**: `'success'`（成功）
     - **3回的中**: `'draw'`（あいこ）
     - **2回以下**: `'failed'`（失敗）
