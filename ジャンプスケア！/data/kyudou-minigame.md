# ティラノスクリプト向け 弓道（的当て）ミニゲーム制作仕様書

## 1. 概要・動作環境
- **概要**: 弓道をモチーフにした、照準と的のタイミングを合わせるミニゲーム。
- **プラットフォーム**: ティラノスクリプト（PC / スマホのタッチ操作両対応）
- **画面解像度**: 1280 × 720 px（基準解像度）
- **実装方式**: JavaScript（`[iscript]` / HTML5 Canvas）を用いて画面上に全画面オーバーレイ等で描画・動作させ、ミニゲーム終了時に結果を変数に格納して元のシナリオに戻る。

---

## 2. 定数・設定パラメータ（調整用オブジェクト）
コードの保守性・調整をしやすくするため、ゲームパラメータは冒頭で一元管理できるオブジェクト形式（`CONFIG`）で定義してください。

```javascript
const CONFIG = {
  // --- 的・判定のサイズ設定 ---
  targetScale: 1.0,         // 的の表示倍率（基準サイズからの変更用）
  hitBoxRadius: 40,         // 「中り」判定となる的中心からの半径（px）

  // --- ブレ（揺らぎ）設定 ---
  initialSwayRadius: 150,   // スタート時の初期ブレ半径（px）
  minSwayRadius: 20,        // 限界（ゲージMAX直前）まで長押しした時の最小ブレ半径（px）
  swayMoveDuration: 800,    // 次の目標点へ移動する時間（ミリ秒）

  // --- 制限時間・判定設定 ---
  maxHoldTime: 3.0,         // 暴発までの長押し時間（秒）※約3秒想定（必要に応じて変更可）
  totalShots: 4,            // 合計射数（4回固定）

  // --- ティラノスクリプト連携変数名 ---
  resultVariableName: 'f.kyudo_result' // 復帰時に代入するティラノ変数
};
```

## 3. 「的のブレ（揺らぎ）」アルゴリズム仕様
ランダムノイズ（微振動）ではなく、プレイヤーが**「狙いを定めている感覚」**を再現するため、照準を中心に的の重心がなめらかな弧を描いて移動する軌道制御を実装してください。

### 【ブレ移動の計算ロジック】
1. **基準点**:
   - 画面中央の固定「照準（クロスヘア）」座標を原点 $(0, 0)$ とする。
2. **現在のブレ半径 $R$ の算出**:
   - 長押し時間 $t$（$0 \text{秒} \sim \text{CONFIG.maxHoldTime}$）の経過に応じて、ブレ半径 $R$ を `initialSwayRadius` から `minSwayRadius` へ連続的に小さく変化させる（長押しするほど拡大＋ブレ幅縮小）。
3. **初期設定（第1目標点）**:
   - クリック/タッチ開始時、ランダムな角度 $\theta_0$ ($0^\circ \sim 360^\circ$) を決定。
   - 目標座標 $P_0 = (R \cdot \cos\theta_0, R \cdot \sin\theta_0)$ へ向かって、的の背景を中心から移動させる。
4. **継続的な軌道移動（対角線 $\pm 45^\circ$ の目標点決定）**:
   - 現在位置の角度が $\theta_{\text{current}}$ である場合、次の目標角度 $\theta_{\text{next}}$ は**対角位置（$\theta_{\text{current}} + 180^\circ$）を中心とした $\pm 45^\circ$ の範囲**からランダムに選定する。
     $$\theta_{\text{next}} = \theta_{\text{current}} + 180^\circ + \text{random}(-45^\circ, +45^\circ)$$
   - 現在のブレ半径 $R$ を用いて、次の目標座標 $P_{\text{next}} = (R \cdot \cos\theta_{\text{next}}, R \cdot \sin\theta_{\text{next}})$ を算出。
5. **補間（なめらかな移動）**:
   - 前の目標点から新しい目標点 $P_{\text{next}}$ へ、イージング関数（`easeInOutSine` など）を用いて `swayMoveDuration`（ミリ秒）でゆっくり移動させる。
   - 到達したら手順4〜5を繰り返す。

## 4. ゲームの進行フロー・詳細ルール

1. **待機状態**:
   - 画面背景に的が表示された状態でスタート。
   - 画面上部UI等に「現在の試行回数（例: 1/4 射目）」および「現在の的中数」を表示。
2. **長押し開始（エイム・溜め）**:
   - 画面中央に照準を表示。
   - マウスダウン（またはタッチ開始）で時間経過ゲージ（0〜100%）が増加開始。
   - 時間経過に伴い背景（的）が連続して拡大（ズームイン）し、同時に**「3. ブレ移動アルゴリズム」**に従って的がなめらかに動く。
3. **暴発処理**:
   - ボタンを放さずにゲージが 100%（`CONFIG.maxHoldTime`）に達した場合、強制的に矢が放たれて画面枠外のあらぬ方向へ飛んで「ハズレ」確定となる。
4. **着弾判定（ボタン離し）**:
   - ゲージ100%未満でマウス（指）を離すと矢が放たれる。
   - 放たれた瞬間の「照準位置」と「的の中心位置」の距離を計算。
   - 距離が `CONFIG.hitBoxRadius` 以内であれば「中り」、それ以外は「ハズレ」と判定。
   - 着弾した位置に着弾点（黒い点）を描画する。過去の試行で残った着弾点も画面上に保持する。
5. **ループとシナリオ復帰**:
   - 1〜4を計4回繰り返し、終了後に的中数に応じてティラノ変数 `f.kyudo_result`（指定の変数名）に以下の文字列を格納してシナリオに戻る。
     - **4回的中**: `'success'`（成功）
     - **3回的中**: `'draw'`（あいこ）
     - **2回以下**: `'failed'`（失敗）

## 5. UI・アセット拡張性
- 的・背景・照準の画像素材を外部から読み込んで差し替えられる設計にすること。
- **フォールバック**: 画像アセットが見つからない場合でも即座に動作テストできるよう、Canvasの基本描画（円・線・グラデーションなど）で代替表示するダミー描画モードを用意すること。
